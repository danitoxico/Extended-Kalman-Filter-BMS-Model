# Extended-Kalman-Filter-BMS-Model

This project implements a Battery Management System (BMS)
capable of estimating the State of Charge (SOC) and State
of Health (SOH) of a lithium-ion battery using an Extended
Kalman Filter (EKF). The model is fully developed in
MATLAB/Simulink and provides a realistic simulation environment
for analyzing battery behavior, degradation, and estimation accuracy.


- How To Use:
1) Open MATLAB
Load the Simulink model:
BatterySOHEstimation.slx

2) Run the initialization script:
BatterySOHEstimationData2
Run the simulation inside Simulink

3) Plot the results by running:
BatterySOHEstimationPlotFinal
